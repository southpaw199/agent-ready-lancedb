# LanceDB: findings log

Observations about the docs collected during agent runs, before they're written up in the [report](report.md). Each finding needs evidence from a run and a check against the current docs page before it goes in the report.

| Severity | Criteria |
| --- | --- |
| **High** | An agent following the docs would fail or get a wrong result. |
| **Medium** | The task succeeds, but only with knowledge the docs don't give or by a route they don't point to. |
| **Low** | Friction or polish. |

No finding is High. Severities were added on October 27, 2026, after the review.
